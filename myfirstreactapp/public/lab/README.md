# Lab demos

Each experiment lives in its own self-contained folder here, e.g.
`public/lab/what3pubs/index.html`, and is served as-is at `/lab/<slug>/`.

Keep every path inside a demo relative (e.g. `./sketch.js`, `./p5.min.js`) so
it works under both `/preview/` and the site root. Then add an entry to
`src/data/lab.js`.
